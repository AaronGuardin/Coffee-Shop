# Project Goal

Build a responsive Coffee Shop website based on the supplied desktop and mobile design mockups and image assets. Complete it in these four steps:

1. **Home** — Build the homepage with navigation, hero, categories, featured menu items, ingredients carousel, and footer.
2. **Menu** — Build the menu page with today’s specials, category navigation, menu items and prices, featured coffee promotion, and footer.
3. **About** — Build the About page to match the supplied designs and use the project’s existing imagery and branding.
4. **Contact** — Build the Contact page with the supplied contact details, map imagery, and responsive layout.

Each step is complete when its page matches the supplied design direction, works on desktop and mobile, and its links and interactive elements function.
